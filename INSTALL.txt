NELLY + DREW v8 — Identity, personality, Switch buttons and voice diagnostics

ONE-FOLDER INSTALL
1. Extract this ZIP.
2. Open https://github.com/Drew24211/nelly-ai (main repository folder, NOT public).
3. Add file > Upload files. Upload ALL extracted files directly into that main folder, replacing existing versions. Do not upload the ZIP itself or a containing folder.
4. Commit. In Render, verify Build Command = npm install and Start Command = npm start. Deploy the latest commit and wait for Live.
5. Open https://nelly-ai.onrender.com and press Ctrl+Shift+R.
6. https://nelly-ai.onrender.com/api/health should report interfaceVersion 8.
No API-key change is needed. server.js now selects the highest-version valid interface across main, public and public/public. It only serves whitelisted main-folder UI files, not private repository files. Other existing files are not deleted.

NEW

Drew has Dynamic Reasoning & Electronic Wisdom, his own blue avatar description, and a calm, strategic, resourceful personality. The server puts the active profile in the chat system prompt.
Memory lets you save a nickname, tone and personal notes. Type remember that… to save a note in chat. Each companion has a separate editable profile. Preferences are browser-local and sent with chat requests. This is persistent context, not model retraining or consciousness.
Voice & Appearance > Microphone & speaker test lets you record five seconds, play it back, try recognition and test the speaking voice. This distinguishes input hardware from a failed speech-recognition service. A recording test does not provide an alternate transcription engine. Chrome or Edge and HTTPS are still required for best browser speech support. Fixes wake-listening restart while speech output is pending.
