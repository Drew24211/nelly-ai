NELLY & DREW v9 — INSTALL

1. Extract this ZIP.
2. Upload ALL extracted files directly into the MAIN folder of Drew24211/nelly-ai on GitHub. Replace matching files. Do not put them into another public folder.
3. Commit. On Render deploy the latest commit, then refresh the site.
4. /api/health should report interfaceVersion 9.

PUBLIC LINK
Your existing Render URL remains the shareable website link. This ZIP does not deploy itself. Visitor customization and memory stay in that visitor's browser. Visitors use your server's Claude allowance.

VOICE DEFAULTS
Drew selects a recognized male browser voice; Nelly selects a recognized female browser voice. Available voices depend on the visitor's operating system/browser. Voice studio saves each companion's voice and settings separately.
Online voice toggle: configure ELEVENLABS_API_KEY in Render Environment, then choose a voice ID in Voice studio for each character. Alternatively set ELEVENLABS_NELLY_VOICE_ID and ELEVENLABS_DREW_VOICE_ID on Render. Do not put API keys into source files or the developer editor.
ElevenLabs has a limited free tier; voice access and usage limits apply. https://elevenlabs.io/pricing
Deepgram also offers introductory credits: https://deepgram.com/pricing

MICROPHONE
Browser recognition still requires supported Chrome/Edge and mic permission. Opera GX may expose microphone capture without a functioning recognition service.
To use server transcription, add DEEPGRAM_API_KEY in Render Environment and redeploy. DEV page > Microphone engine > Auto. Tap mic to start, tap again to finish/send. A recording is capped at 30 seconds/8 MB. Audio is transmitted to Deepgram for transcription; not saved by this application server. Wake phrase uses browser recognition only.
Hardware capture and live provider speech could not be verified remotely; these services require your configured keys.

MUSIC & EFFECTS
Nelly: Pink Daydream. Drew: Blue Orbit. Both are original included ambient recordings, free to use in this project. Music begins after a user interaction because browsers restrict autoplay.
Drew has an original anime-inspired eye-activation synth effect, not the original Naruto Sharingan recording. Import your own permitted audio in DEV page > Drew button sound.
Blush is a temporary visual overlay triggered by sweet words, no separate romance mode needed.

DEV PAGE
Type DEV page in chat. This is a local customization editor, not a secure admin login. Voice/memory/music tools, microphone engine, animation pace, accent, custom CSS, portrait/GLB import and isolated HTML widget previews are available. Changes stay on the current browser. Source JavaScript changes need a reviewed repository edit.

FUTURE AI PROVIDERS
AI Model dropdown saves future provider/model templates. Claude remains the only connected chat adapter. No OpenAI or DeepSeek requests are made. Adding a future provider requires a server adapter and its credentials; entering a name alone does not connect it.
