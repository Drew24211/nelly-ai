NEW
Live news: GDELT links for World/Bahamas/Technology/Sports, fetched on request and refreshed every 5 minutes while the news panel is open. Data is cached on the server for 5 minutes. Current public source may be unavailable; no sample news is substituted. The upstream returned 503 during this run. Mocked validation/cache/link tests passed.
Poly Haven: server catalog adapter, verified source access. Links to asset pages with CC0 download options. Powered by Poly Haven. Import a self-contained GLB after downloading/converting; these props are not rigged Nelly/Drew characters.
Kokoro: experimental free on-device engine. Open Voice, choose a voice, Download & initialize Kokoro, then select Kokoro speech engine and save. Downloads a large ONNX model from Hugging Face with kokoro-js/Transformers.js through jsDelivr. No API key. Browser generation has not been verified end-to-end; hardware/memory/network compatibility vary. Default browser voices remain available.
Connections: future integration plans have category/name/docs URL/environment variable name/notes. Plans do not connect arbitrary APIs. No keys stored there.
